# Economist Briefing

Weekly, lightly filtered previews of unread newsletters from the exact Gmail label `Economist`.

Planned public URL: <https://filipoclawi.github.io/economist-briefing/>

- Saturday–Friday editions with navigation across the archive
- One concise preview per newsletter title
- Clean direct `economist.com` links
- Rough read/watch time before every click
- Red-dot Insider and Inside-series video briefings are visually distinct and explicitly flagged
- No email addresses, Gmail identifiers, tracking redirects, recipient data or private attribution

Run local verification with `python3 tests/ui_smoke.py`.
